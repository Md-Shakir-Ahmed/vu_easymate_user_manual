Visual Capture Execution Instructions#

For implementation teams executing visual UI captures in a live test environment: 1. Ensure a local or staging web server is running (php artisan serve on port 8000). 2. Seed the database with representative demo records (php artisan db:seed). 3. Capture full-window or element-level screenshots for each screen number above. 4. Store screenshots as PNG images under docs/user-manual/screenshots/{module_id}_{screen_id}.png. 5. Update the Capture Status column in this document from Pending (Not captured) to Captured [filename] upon physical image verification.
